# CoastSat 위성영상 전처리 데스크톱

기존 `app.py` 웹 앱은 유지합니다. 새 앱의 진입점은 `desktop_app.py`입니다.
해안선 탐지·트랜섹트·조석보정 등 후속 분석은 포함하지 않습니다.

## 사용자 실행

배포 ZIP 전체를 쓰기 가능한 폴더에 압축 해제하고 `CoastSatPreprocess.exe`를 실행합니다.
EXE 옆의 `env`, `desktop` 폴더를 옮기거나 삭제하지 마세요. Python 별도 설치는 필요 없습니다.
Microsoft Edge WebView2가 있으면 독립 창으로 열립니다. 사용할 수 없으면 기본 브라우저에서
로컬 화면을 열며 종료 안내창의 확인 버튼을 누를 때 앱이 종료됩니다.
인터넷은 Google 영상 수집·로그인에만 필요합니다.

1. **내 파일 전처리:** GeoTIFF 또는 좌표정보가 포함된 JP2를 추가합니다. 큰 파일은 업로드
   대신 경로를 입력합니다. 단일 다중밴드 파일 또는 같은 촬영 장면의 개별 밴드 파일을 지원합니다.
2. Blue/Green/Red/NIR/SWIR1 밴드를 직접 지정합니다. RGB만 있으면 3밴드 모드를 선택합니다.
   밴드·위성·보정 수준을 자동 추측하지 않습니다. Sentinel SAFE/ZIP·Landsat TAR 전체 자동 해석은
   지원하지 않습니다. 해당 자료는 필요한 개별 래스터 파일로 제공해야 합니다.
3. 구름 정보가 있으면 형식과 밴드를 지정합니다. 없으면 구름을 제거하지 않고 미확인으로 기록합니다.
4. Landsat 7/8/9의 5밴드 영상과 PAN이 있을 때 선명화를 선택할 수 있습니다.
5. **미리보기 갱신**으로 원본과 처리 결과를 비교합니다. 설정을 바꾸면 다시 갱신하세요.
6. 결과 저장 폴더를 지정하고 전처리를 시작합니다. 진행 상태와 오류는 화면 하단에서 확인합니다.

## 설정을 바꾸며 미리보기

내 파일 전처리와 CoastSat 폴더 전처리 모두 미리보기를 지원합니다. CoastSat 폴더에서는
**장면 목록 불러오기 → 미리볼 장면 선택 → 미리보기 갱신** 순서로 사용합니다.
폴더의 최종 저장은 전체 목록에 같은 설정을 적용하며, 미리보기는 선택한 한 장면만 처리합니다.

- 구름 확률 기준: s2cloudless 데이터가 있을 때 사용합니다. 기준보다 높은 확률에 CoastSat
  마스크 정리를 적용합니다. 낮출수록 더 많은 영역이 구름 후보가 됩니다. QA60 구름 판정은
  별도로 합쳐지므로 기준을 올려도 QA60의 구름 영역은 남을 수 있습니다.
- 구름 픽셀 제외 켜기/끄기, Landsat 모래·포말 오인 완화, 지원되는 PAN 선명화와 밴드별
  스케일·오프셋을 변경해 비교할 수 있습니다.
- 원본과 처리 결과는 나란히 표시합니다. 원본 보기는 밴드 정렬·스케일을 적용하되 구름 제외와
  선명화 전인 영상입니다. 양쪽은 동일한 명암 기준을 사용합니다.
- 구름·결측 마스크를 겹쳐 보거나 투명도를 조절할 수 있습니다. 주황=구름, 회색=결측,
  보라=구름 정보 미확인입니다. 투명도는 화면 표시에만 영향을 줍니다.
- 남는 픽셀·구름·미확인·결측의 비율을 전체 픽셀 수 기준으로 표시합니다.
- 설정이나 입력 파일이 바뀌면 이전 미리보기라는 경고를 표시합니다. 아래에 표시되는 기준값은
  실제로 미리보기를 계산했던 값입니다. 최종 저장은 저장 버튼을 누를 때의 현재 설정을 사용합니다.

미리보기는 최종 저장과 같은 원본 해상도로 계산한 뒤 화면만 축소하므로 큰 영상은 시간이
걸릴 수 있습니다. 최종 TIFF를 만들지 않고 사용자 작업 폴더의 jobs 아래 PNG와 설정 기록만
저장합니다. 처리 결과가 모두 가려지면 미리보기에서 이를 확인할 수 있지만 최종 저장은 거부합니다.

**Google에서 영상 수집:** 본인의 Earth Engine 사용 가능 Google 계정과 Cloud 프로젝트 ID가
필요합니다. 기본 브라우저에서 로그인하고 사용할 작은 영역·기간·위성을 선택합니다.
종료일은 미포함입니다. 수집 후 **CoastSat 폴더 전처리**에서 이어서 실행합니다.
인증 정보는 Earth Engine의 사용자별 기본 위치에 저장되고 배포물이나 저장소에 포함하지 않습니다.

## 결과

- `preprocessed.tif`: 좌표계·위치정보 유지, float32, Blue/Green/Red[/NIR/SWIR1] 순서.
  제외 픽셀은 NaN NoData입니다. 파일 메타데이터 또는 사용자가 지정한 scale/offset을 적용합니다.
- `masks.tif`: 1밴드=제외(0/1), 2밴드=구름(0 맑음/1 구름/255 미확인), 3밴드=결측(0/1).
  구름 정보를 전혀 제공하지 않은 경우 미확인 픽셀을 자동 제외하지 않습니다. 제공된 마스크가
  일부 영역만 덮으면 미확인 영역을 제외합니다.
- `preview.png`: 2–98 백분위 명암 조정이 적용된 RGB 미리보기. 분석 값은 TIFF에 있습니다.
- `report.json`: 입력 파일, 밴드, 설정, 좌표계, 유효 픽셀 비율과 경고.
- `INCOMPLETE.txt`가 남은 폴더는 중단되거나 실패한 미완료 결과입니다.

기본 출력 격자는 Blue 밴드이며 선명화 시 PAN 격자입니다. 연속 영상은 bilinear,
분류·QA·구름 확률은 nearest 보간을 사용합니다. ROI 자르기, 대기보정, 사용자 지정 출력 좌표계,
범용 영상의 자동 밴드 식별은 포함하지 않습니다.

초기 버전 메모리 제한: 입력·출력 영상 각각 1,200만 픽셀 이하. 수집 영역은 경·위도 폭 각각
0.15도 이하. 메모리 내 처리이므로 16GB RAM 이상을 권장하며 큰 장면은 작은 영역으로 나누어야 합니다.

## 개발·빌드

검증한 빌드는 Python 3.12의 독립 실행 환경과 Windows용 GDAL wheel을 포함합니다.
`environment-desktop.yml`은 conda 환경 대안이며 실제 Windows 배포 빌드는
`requirements-desktop.lock.txt`와 `build_desktop.py`를 사용합니다.

```powershell
# 의존성이 설치된 독립 Python 환경에서 실행
python -m unittest discover -s tests -v
python -m streamlit run desktop_app.py
python build_desktop.py --runtime C:\path\to\portable-python --output C:\path\to\CoastSatDesktop
```

runtime은 Python 실행파일·표준 라이브러리·의존성을 모두 포함하는 독립 환경이어야 합니다.
이 배포판의 Python 원본: https://www.nuget.org/packages/python/3.12.10
NuGet 패키지를 압축 해제한 `tools` 폴더를 runtime으로 사용하고, 해당 Python으로
`python -m pip install -r requirements-desktop.lock.txt`를 실행해 의존성을 준비합니다.
일반 venv는 원본 Python 설치에 의존하므로 그대로 배포하지 마세요. 빌드는 PyInstaller로
얇은 실행기를 만들고 runtime을 `env`로 복사합니다. 소스와 라이선스도 함께 제공합니다.
`CoastSatPreprocess.exe --smoke-test`는 로컬 화면 서버가 뜨는지 확인하고 종료합니다.
로그 기본 위치는 사용자 Documents/CoastSatDesktop입니다. 개발·시험 시 `COASTSAT_STATE_DIR`로
별도 경로를 지정할 수 있습니다.

## 검증 범위

합성 GeoTIFF로 좌표계 보존, NoData 처리, 서로 다른 해상도의 마스크 정렬,
QA60 복합 비트, 비중첩 입력 거부를 시험합니다. 실제 사용자 위성영상 샘플과 Google 로그인·수집은
사용자 데이터/계정으로 별도 검증해야 합니다. Python 미설치 깨끗한 PC 검증 전에는 시험 배포판입니다.

CoastSat 원본: https://github.com/kvos/CoastSat · GPL-3.0.
이 앱은 원본의 구름 마스크·PCA 선명화 함수를 사용합니다. 일반 영상 입력에는 명시적 밴드 지정과
GDAL 좌표 정렬을 추가하고 Sentinel QA60은 두 구름 비트가 함께 설정된 경우도 처리합니다.
현재 CoastSat 폴더 구조를 지원하며 오래된 폴더 구조는 자동 변환하지 않습니다.
