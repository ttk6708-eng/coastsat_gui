# CoastSat Studio — 독립 Windows 프로그램

Streamlit·웹뷰·로컬 웹 서버 없이 Qt Widgets로 실행하는 전처리 전용 데스크톱 시험판입니다.
기존 웹 앱 소스는 저장소에 그대로 있으며, 이 배포물에서는 사용하지 않습니다.

## 실행

1. ZIP 전체를 쓰기 가능한 폴더에 압축 해제합니다.
2. `CoastSatStudio.exe`를 더블클릭합니다.
3. EXE 옆 `env`, `desktop`, `coastsat`, `assets` 폴더를 함께 유지합니다.

Python이나 브라우저를 따로 준비할 필요가 없습니다. **Google 로그인 때만** 기본 브라우저가
열립니다. 파일 전처리에는 로그인과 인터넷 연결이 필요하지 않습니다.

## 화면

- **왼쪽 자료 탐색:** 장면 목록, 선택·제거. 제거해도 원본 파일은 삭제되지 않습니다.
- **가운데 영상 비교:** 원본과 결과를 나란히 표시. 휠로 확대, 드래그로 이동하며 두 화면을
  연동할 수 있습니다. 전체 보기와 1:1은 화면용 미리보기 픽셀 기준입니다.
- **오른쪽 처리 속성:** 구름 기준·구름 제외·모래/포말 오인 완화·PAN 선명화, 미리보기, 저장.
- **아래 작업 기록:** 진행·오류 로그와 저장 결과 목록. 결과 목록을 더블클릭하면 폴더가 열립니다.
- 패널 경계를 드래그해 너비·높이를 조절하고, 닫은 패널은 보기 메뉴에서 다시 열 수 있습니다.
- **설정 설명:** 각 설정 옆 `?`를 누르면 해당 항목의 상세설명이 열립니다. 마우스를 올리면
  짧은 설명도 표시됩니다. 오른쪽 **설정 상세설명** 또는 **도움말 → 전처리 설정 상세설명**에서
  구름 기준 예시, 구름 제외와 화면 표시의 차이, 선명화, 자동 처리, 저장 순서를 읽을 수 있습니다.
  설명 창은 인터넷 없이 열리며, 설정이 비활성화된 상태에서도 사용할 수 있습니다.

## 내 영상 파일

### 심화 1단계: 입력 점검·미리보기

장면을 등록하고 오른쪽 **1단계 · 입력 점검·미리보기**를 누르면 구름 제거 전 RGB와
밴드별 크기·픽셀 크기·좌표계·정렬 필요 여부·적용 scale/offset을 확인할 수 있습니다.
표의 밴드를 선택하고 **선택 밴드 상세 보기**를 누르면 원값/보정값 범위, NoData, 처리 수준
메타데이터를 확인합니다. 통계는 최대 256×256 표본 기준이며 전체 영상 통계가 아닙니다.
RGB는 표시용 좌표 정렬·보정값 적용·명암 조절만 사용합니다. 구름 제거, PAN 선명화,
대기보정은 적용하지 않습니다. 원본은 변경하지 않으며 별도 `input-review.json`을 저장합니다.
문제가 있으면 **밴드·보정 설정 수정** 후 다시 점검하세요. 보정 여부를 자동 추정하거나
Sentinel-2 오프셋을 일괄 차감하지 않습니다. AI 구름 판정은 별도의 선택형 비교 미리보기로 제공하며 이 입력 점검에는 적용하지 않습니다.

**영상 여러 개 추가**에서 촬영 장면별 GeoTIFF/JP2 파일을 함께 선택합니다. 파일 하나에
RGB 또는 5개 영상 밴드가 들어 있는 경우를 위한 기능입니다. 선택 파일의 밴드를 지정하고,
구성이 같은 파일에만 **선택 설정을 나머지에 복사**를 사용하세요. 밴드 구성을 자동 추측하지 않습니다.
미설정 파일은 밴드를 지정하거나 목록에서 제외해야 등록할 수 있습니다.

등록 후 왼쪽 **위로 / 아래로**로 순서를 정하고 **전체 순차 전처리·저장**을 누르면 목록 순서대로
하나씩 처리합니다. 한 장면에서 실패해도 다음 장면을 계속 처리합니다. 중지하면 후속 장면은
처리하지 않으며 이미 완료된 결과는 보존합니다. 자동 재시작·실패 항목 자동 재시도는 하지 않습니다.

하단 **전처리 상세 · 순차 진행**에서 장면별 대기·처리 중·완료·실패·중지 상태를 볼 수 있습니다.
장면을 선택하면 입력 확인, 밴드별 정렬·값 보정, 구름·결측 비율, PAN 선명화 여부,
최종 유효 픽셀 수와 저장 단계가 표시됩니다. 진행률은 전체 장면 중 처리 종료된 개수 기준이며
남은 시간의 추정값이 아닙니다. 전체 기록은 작업 폴더의 `batch-report.json`, 장면별 처리 단계는
결과의 `report.json`에 저장됩니다. 로컬 전처리에는 Google 로그인·KML·인터넷이 필요 없습니다.

**밴드 파일 묶기**에서 같은 촬영 장면의 GeoTIFF/TIFF 또는 좌표정보가 있는 JP2 파일을 고릅니다.
여러 파일을 한 번에 선택할 수 있습니다. Blue/Green/Red/NIR/SWIR1 밴드를 직접 지정하거나,
RGB만 있으면 3밴드 모드를 사용합니다. 구름 정보와 PAN 밴드는 있을 때만 지정합니다.

원본 배포 ZIP/TAR/SAFE 전체 자동 해석은 지원하지 않습니다. 필요한 개별 래스터 파일을
선택해야 합니다. 파일별 밴드 순서·방사보정 수준을 자동 추측하지 않습니다.
**밴드·보정 설정 수정**에서 일반 파일의 밴드와 scale/offset을 다시 바꿀 수 있습니다.

## CoastSat 폴더와 Google 수집

**CoastSat 폴더**에서는 L5/L7/L8/L9/S2 하위 폴더를 포함한 사이트 폴더를 고릅니다.
현재 CoastSat 다운로드 형식의 밴드와 구름 정보를 읽어 장면 목록을 만듭니다.
CoastSat 형식은 밴드와 보정계수가 정해져 있어 일반 파일용 밴드 편집을 사용하지 않습니다.

**Google 수집**에서는 본인의 Earth Engine 사용 가능 계정과 Cloud 프로젝트 ID를 사용합니다.
첫 사용 시 프로젝트 ID를 입력하고 **Google 로그인 / 계정 변경**을 누릅니다. 기본 브라우저에서
Google 계정을 선택하고 권한을 허용하면 같은 창에 **GEE 연결 성공**이 표시됩니다.
이미 인증했다면 **GEE 연결 확인**을 사용할 수 있습니다. 인증 중지·창 닫기로 대기를 취소할 수 있으며,
5분 동안 응답이 없으면 중지합니다. Google 로그인만으로 GEE 프로젝트 등록·권한이 생기지는 않습니다.
공식 안내: https://developers.google.com/earth-engine/guides/auth

**KML 파일 불러오기**에서 수집 영역을 지정할 수 있습니다. 여러 다각형이 있으면 목록에서 하나를
선택합니다. 윤곽 미리보기는 북쪽이 위이며 배경지도는 없습니다. 내부 구멍도 검색 영역에 유지됩니다.
점·경로만 있는 파일은 사용할 수 없으며, Polygon 영역을 포함한 KML로 저장해 주세요.
파일은 5MB 이하, 영역은 경도·위도 폭 각각 0.15도 이하, 위도 ±85도 안쪽이어야 합니다.
KML은 로컬에서 읽고 선택한 좌표를 GEE 수집 요청에 사용합니다. GEE 자산으로 업로드하지 않습니다.
검색은 선택한 다각형을 사용하지만 CoastSat 다운로드 파일은 해당 영역을 감싸는 사각형입니다.
KML 경계대로 잘라내는 기능은 포함하지 않습니다. 영역·기간·프로젝트는 수집 폴더의
`collection-request.json`에도 기록합니다.

영역·기간·위성을 정한 뒤 **선택 영역의 영상 수집**을 누릅니다.
종료일은 포함하지 않습니다. 수집 완료 후 장면 목록에 영상을 추가합니다.
인증 정보는 Earth Engine의 사용자별 기본 위치에 저장되며 배포물·저장소에 포함하지 않습니다.
최근 프로젝트 ID는 사용자 작업 폴더에 저장됩니다. 프로그램은 Google 비밀번호를 입력받거나 저장하지 않습니다.

## 설정 비교와 저장

1. 장면을 선택하고 오른쪽 설정을 바꿉니다.
2. **미리보기 갱신**을 누릅니다. 실제 원본 해상도로 계산하므로 큰 영상은 시간이 걸립니다.
3. 원본과 처리 결과를 비교합니다. 원본 보기는 정렬·스케일을 적용하되 구름 제외·선명화 전입니다.
4. 마스크를 겹쳐 보거나 투명도를 조절합니다. 주황=구름, 회색=결측, 보라=구름 정보 미확인.
5. **선택 장면 저장** 또는 **전체 장면 저장**을 누릅니다. 최종 저장은 현재 설정을 사용합니다.

구름 확률 기준은 s2cloudless 정보가 있을 때만 적용됩니다. 기준보다 높은 확률을 구름 후보로
판정한 뒤 CoastSat 마스크 정리를 적용합니다. QA60 구름 판정은 별도로 합쳐집니다.
구름 확률이 없는 영상에는 기준값 조절이 비활성화됩니다. 구름 정보가 전혀 없으면 구름을
제거하지 않고 미확인으로 표시합니다. 모래/포말 오인 완화는 Landsat QA_PIXEL에만 적용됩니다.

설정은 장면별로 유지합니다. **현재 설정을 전체 장면에 적용**으로 일괄 적용할 수도 있습니다.
선명화는 PAN이 있는 Landsat 7/8/9에서만 가능합니다. 설정이나 원본 파일이 바뀌면 이전
미리보기라는 안내를 표시합니다. 두 화면과 저장 PNG는 같은 명암 기준을 사용합니다.

결과 폴더에는 좌표정보를 유지한 `preprocessed.tif`, 3밴드 `masks.tif`, `preview.png`,
`report.json`이 생성됩니다. 마스크는 제외(0/1), 구름(0/1/255 미확인), 결측(0/1) 순서입니다.
제외 픽셀은 전처리 TIFF에서 NaN NoData입니다. `INCOMPLETE.txt`가 남은 폴더는 미완료 결과입니다.
투명도·확대·이동은 화면에만 영향을 주며 분석 값은 바꾸지 않습니다.

## 범위와 제한

해안선 추출·후속 분석·대기보정·관심영역 자르기·사용자 지정 출력 좌표계는 포함하지 않습니다.
출력 격자는 Blue 밴드, 선명화 시 PAN 밴드 기준입니다. 연속값은 bilinear, QA는 nearest로 정렬합니다.
입력·출력 영상당 최대 1,200만 픽셀, Google 수집은 경도·위도 폭 각각 0.15도까지입니다.
메모리 내 처리이므로 16GB RAM 이상을 권장합니다. 앱을 닫으면 진행 중인 처리도 중단됩니다.
장면 목록은 현재 실행 중에만 유지되며 앱을 다시 열면 파일을 다시 불러와야 합니다.

합성 영상으로 기능 시험을 수행했습니다. 실제 사용자 영상·Google 수집·Python이 없는
별도 PC의 검증은 아직 남아 있습니다. 상세 내용은 `VALIDATION_NATIVE.md`를 참고하세요.

## 개발자 빌드

공식 Python NuGet 3.12.10의 `tools` 폴더를 독립 runtime으로 사용합니다.
https://www.nuget.org/packages/python/3.12.10

```powershell
python -m pip install -r requirements-native.lock.txt
python native_app.py
python build_native.py --runtime C:\path\to\portable-python --output C:\path\to\CoastSatStudio
```

`requirements-native.lock.txt`에는 Streamlit·pywebview를 포함하지 않습니다.
빌드는 실행기를 만들고 전체 runtime과 소스를 함께 복사합니다. 원본 Python 설치를 요구하는
일반 venv는 그대로 배포하지 마세요. `CoastSatStudio.exe --smoke-test`는 Qt 화면을
화면 밖에서 구성한 뒤 종료하며 사용자 작업 폴더에 진단 JSON을 기록합니다.
기본 작업 폴더는 사용자 Documents/CoastSatDesktop입니다. `COASTSAT_STATE_DIR`로 변경할 수 있습니다.

CoastSat 원본: https://github.com/kvos/CoastSat · GPL-3.0.

## AI 구름·그림자 비교 (선택형 시험 기능)

AI 포함 버전에서 오른쪽 `AI 구름·그림자 비교 · 시험 기능`을 펼쳐 `AI 비교 미리보기`를 누릅니다.
모델이 없으면 `AI 모델 받기`를 먼저 누릅니다. 공식 Hugging Face의 NickWright/OmniCloudMask 저장소에서
버전 4 모델 두 개(총 57,805,992 bytes)를 받으며 SHA-256으로 검증합니다.
모델이 포함된 배포본은 처음부터 오프라인 사용이 가능합니다. 사용자 영상은 업로드하지 않습니다.
기본 버전에는 PyTorch 실행 환경이 없으므로 AI 포함 버전을 사용해야 합니다.

왼쪽은 기존 품질정보/구름확률 판정, 오른쪽은 AI 판정입니다. 동일한 RGB 영상 위에 색상으로 표시합니다.
AI 색상: 주황=두꺼운 구름, 노랑=얇은 구름, 파랑=그림자, 회색=결측/미확인.
기존 판정의 보라색은 구름 정보 미확인입니다. 색상 진하기는 표시만 바꿉니다.
일반 구름 확률 기준은 기존 마스크에만 적용되며 AI 분류 기준을 바꾸지 않습니다.
일반 전처리 저장에는 AI 마스크를 적용하지 않습니다. AI 판정 TIFF와 기록은 비교 작업 폴더에 별도로 저장됩니다.
AI 비교 TIFF: 1번 밴드 0=맑음, 1=두꺼운 구름, 2=얇은 구름, 3=그림자, 255=미확인;
2번 밴드 0=기존 판정과 일치, 1=불일치, 255=비교 불가. 불일치는 정확도 점수가 아닙니다.

AI에는 선명화/구름 제외 전 Red·Green·NIR를 파랑 밴드 격자로 정렬해 입력합니다.
RGB만 지정하면 NIR를 0으로 대체하는 시험 모드이며 별도 경고를 표시합니다.
가로·세로 각각 96픽셀 이상, 기존 입력 제한 1,200만 픽셀 이하를 지원합니다.
권장 해상도는 10–50m이며 범위 밖/미터 해상도를 판단할 수 없는 좌표는 경고합니다.
모델에 2–98% 화면용 명암 스트레칭을 적용하지 않습니다. CPU fp32, batch 1, patch 512/overlap 128을 사용합니다.
큰 영상은 수 분 이상 걸릴 수 있으며 메인 화면의 작업 중지로 취소할 수 있습니다.
실제 해안 영상의 파도·모래·어두운 바다에 대한 정확도 향상은 아직 검증하지 않았습니다.

개발 환경 설치: 먼저 requirements-native.lock.txt의 기본 환경을 구성합니다.
그 뒤 `python -m pip install torch==2.8.0+cpu torchvision==0.23.0+cpu --index-url https://download.pytorch.org/whl/cpu`
및 `python -m pip install omnicloudmask==1.7.1 numpy==1.26.4 rasterio==1.4.3`를 사용합니다.
NumPy는 기존 GDAL과 호환되는 1.26.4를 유지합니다. 정확한 AI 실행환경은 requirements-ai.lock.txt에 기록합니다.
모델 다운로드 없이 추론하도록 로컬 가중치를 직접 로드하며 사용자 모델 파일/피클을 로드하지 않습니다.

소스 저장소에는 큰 글꼴 파일을 제외합니다. `python download_font.py`로 공식 Noto Sans KR를
고정 버전 URL에서 받고 SHA-256으로 확인합니다. `build_native.py`도 이를 자동 수행합니다.
완성 배포본에는 글꼴이 포함되어 있습니다. AI 오프라인 배포본 빌드 시 `--models <모델폴더>`를
추가하면 검증된 두 모델만 배포본에 복사합니다.

## 구름 확률 0 및 보정 상태 점검
CoastSat Sentinel-2의 ms 5번 구름 확률 밴드에서 NoData=0이 지정된 경우,
파일의 NoData로 자동 생성된 마스크에 한해서 확률 0을 유효값으로 해석합니다.
영상 밴드의 결측 영역, 명시적 마스크/알파, 다른 형식의 입력 NoData는 유지합니다.
QA60의 0은 자료 공백 등과 구분할 근거가 없어 임의로 맑음으로 복구하지 않습니다.

입력영상 확인의 `보정 상태 · 판단 근거` 탭에서 방사·대기·정사·기하 보정 상태를 확인할 수 있습니다.
Sentinel-2 영상 밴드 모두에 일치하는 L1C/L2A 제품 수준 정보가 있어야 대기 보정 상태를 식별합니다.
CoastSat TXT의 좌표·영상 품질 PASSED는 보정 완료 증거로 사용하지 않습니다.
이 기능은 상태 설명이며 대기·정사·기준점 기반 기하 보정 기능을 추가한 것은 아닙니다.
# 지역·촬영 범위 점검

상단 **지역·촬영 범위 점검**을 누르고 `S2` 폴더를 포함한 지역 폴더를 추가합니다.
여러 지역을 등록하고 드롭다운으로 전환할 수 있습니다. 현재 이 점검은 CoastSat S2 형식을 지원합니다.

1. 파일 목록의 ms/swir/mask/meta 누락·중복을 확인합니다. 목록 생성 시 영상을 처리하지 않습니다.
2. **처음·중간·마지막 3장 선택** 또는 Ctrl/Shift로 필요한 행을 선택합니다.
3. **선택 장면 정보 점검**으로 선택한 파일의 헤더와 TXT만 읽습니다.
4. 같은 지역의 점검된 장면 중 기준 영상을 선택하고 다른 행을 클릭합니다.
5. 파란 기준 범위와 주황 선택 범위, 양쪽 면적 대비 공통 범위 비율을 확인합니다.
6. **점검 기록 저장**으로 전체 목록·점검한 장면·기준별 비교를 JSON에 저장합니다.

범위 비율은 영상 외곽 다각형 기준입니다. 실제 유효 픽셀·구름 비율이나 위치 정확도를 뜻하지 않습니다.
같은 투영 좌표계 안에서 비교하며 다른 좌표계는 안내 후 중단합니다. 픽셀 전처리·재투영·위치 교정은 하지 않습니다.
점검 결과는 실행 시점의 정보입니다. 입력 파일을 변경한 경우 다시 점검하세요.

# 구름·결측 단계별 확인

미리보기를 갱신한 뒤 **구름·결측 단계별 확인**을 누릅니다. 처리 전 비교 영상,
결측, 구름·미확인 판정, 실제 제외 영역, 최종 결과를 선택해 볼 수 있습니다.
색상 진하기와 표시 단계는 처리 설정을 변경하지 않습니다. 설정 변경은 메인 화면에서
한 뒤 미리보기를 다시 갱신하세요. 오래된 결과는 단계별 창을 새로 열 수 없도록 안내합니다.

**추가 설정 → 공통 영역 기준 영상 선택**에서 같은 지역의 ms GeoTIFF를 지정하면,
전체 영상과 공통 영역 각각의 구름·결측·미확인·실제 제외·최종 유효 픽셀 수와 비율을 계산합니다.
기준은 장면별로 유지되며 전체 설정 적용 버튼으로 다른 지역에 복사되지 않습니다.
공통 영역은 현재 처리 격자의 픽셀 중심이 기준 영상 외곽 안에 있는 영역입니다.
기준 영상의 구름/결측까지 교차 검사하지 않으며, 최종 저장 영상을 자르지 않습니다.
겹치는 픽셀이 없으면 0% 품질로 오해하지 않도록 계산 불가로 표시합니다.
미리보기의 `preview.json`과 최종 저장의 `report.json`에 동일한 품질 통계 구조를 기록합니다.
AI 마스크의 일반 결과 적용과 실제 위치 보정은 포함되지 않습니다.

# 해안선 후보 추출 · 1단계 시험 기능

CoastSat Sentinel-2 장면을 선택하고 **해안선 추출 → 해안선 후보 추출·확인**을 누릅니다.
현재 구름 확률 기준과 밴드 설정으로 다시 처리합니다. 구름 제외를 켜야 실행됩니다.
첫 버전은 미터 단위 투영좌표·정사각형 격자·200만 픽셀 이하의 CoastSat S2 자료만 지원합니다.
일반 GeoTIFF와 Landsat 해안선 추출은 아직 지원하지 않습니다.

1. 최소 모래 영역, 최소 후보선 길이, 구름 주변 제외 거리를 확인하고 추출합니다.
2. 처리 전 영상 → 모래·포말·물 분류 → 후보선 겹쳐 보기로 단계별 확인합니다.
3. 확대해서 검토한 후보만 체크하고 **선택한 후보선 확인·저장**을 누릅니다.
4. 새 폴더에 WGS84 경위도 GeoJSON, PNG, 원래 투영좌표와 설정이 담긴 JSON을 저장합니다.

기본값은 모래 영역 1000m², 후보선 길이 500m, 구름 주변 300m이며 지역별 권장값 확정을 뜻하지 않습니다.
결측 주변은 30m를 제외합니다. 구름 판정 미확인 영역도 제외합니다.
구름 등에 의해 끊긴 부분은 별도 선으로 유지하고 분리 후 최소 길이를 적용합니다.
후보가 없거나 아무것도 선택하지 않으면 저장하지 않습니다. 설정을 바꾸려면 메인 화면에서 다시 추출합니다.
미선택 상태에서는 모든 후보를 표시하며, 하나라도 체크하면 체크한 후보만 표시합니다.

내장 CoastSat S2 분류 모델과 특징 계산을 사용하고, SWIR/Green 지수에 모래·물 균형 Otsu 임계값을 적용합니다.
모래가 50픽셀 미만이거나 물 분류가 없으면 전체 유효 영역 Otsu로 전환하고 이를 기록합니다.
동봉된 upstream `find_wl_contours2`의 NIR/SWIR 임계값 열 혼용을 그대로 호출하지 않습니다.
임계값 산출과 등고선 추출 모두 같은 `(SWIR-G)/(SWIR+G)` 지수를 사용하도록 데스크톱 어댑터에 구현했습니다.
균형 표본 선택에는 고정 seed=0을 사용합니다. 원본 CoastSat 파일은 변경하지 않습니다.
좌표는 CoastSat의 픽셀 원점 관례를 유지하며 별도 반 픽셀 이동을 넣지 않습니다.

모델은 SHA-256으로 동봉 파일만 검증하여 읽습니다. 학습 scikit-learn 버전과 실행 버전 차이를 화면에 안내합니다.
호환성 테스트는 신경망 가중치의 직접 순전파와 예측 결과를 비교하며 과학적 정확도 검증을 대체하지 않습니다.
해안선 후보는 조위 보정 전 관측 수제선입니다. 항만·하천·내륙 수역도 포함될 수 있습니다.
현재는 후보 단위 선택만 가능하며 부분 잘라내기, 날짜별 일괄 추출, 기준 연도 비교, 침식·퇴적 판정은 후속 단계입니다.
기존 전처리 저장과 AI 비교 기능은 그대로 유지됩니다. 외부 AI 모델을 새로 다운로드할 필요는 없습니다.
